\# Odoo 2FA Shield



\*\*Professional Two-Factor Authentication and Account Security for Odoo\*\*



Odoo 2FA Shield is designed to strengthen Odoo account security through configurable MFA enforcement, authenticator applications, administrative recovery, user enrollment management, and security auditing.



\## Features



\- Configurable MFA enforcement

\- User, group, department, and account-type policies

\- TOTP authenticator support

\- Administrative MFA resets and recovery workflows

\- Recovery codes

\- Email invitations and reminders

\- Security audit logging

\- User self-service enrollment

\- Optional HR integration



\## Compatibility



\- Odoo 17.0

\- Odoo 18.0

\- Odoo 19.0



Each version is maintained on its own Git branch.

\## Repository Structure



The `17.0`, `18.0`, and `19.0` branches contain the module source code for their respective Odoo versions. The default branch provides project documentation and release archives.



\## Installation



Download the ZIP package matching your Odoo version, extract it into your custom addons directory, update the Apps List, and install the module.



\*\*Important:\*\* Test on a staging database before production deployment. Compatibility and security should be validated on each supported Odoo version.
