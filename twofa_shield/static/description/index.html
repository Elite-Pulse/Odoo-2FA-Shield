2FA Shield

Enforce two-factor authentication on every Odoo account — without locking yourself out.

Passwords get stolen. 2FA Shield makes TOTP two-factor authentication mandatory, manageable and auditable: you decide who must use it, admins can reset it in one click, and it works after a classic login and after Microsoft Azure / OAuth single sign-on.

Everything you need to roll out 2FA properly

Admin on/off switch

Enable or disable enforcement from Settings any time. No uninstall, no data loss.

Flexible policies

Target everybody, internal users, portal users, access groups, companies, specific users — or HR departments (bridge module included).

Per-user override

Force 2FA on one account or exempt a break-glass account, whatever the policies say.

Password and SSO

Hooks into Odoo's native second-step, so it also runs after Microsoft Azure / Google / any OAuth login. Optionally trust the SSO provider's own MFA.

Reset & recovery wizard

Lost phone or lost Azure account? Reset 2FA, open an emergency bypass window, exempt the user and send a password-reset e-mail for a local account.

Recovery codes

10 one-time codes shown at enrolment, stored only as salted hashes. Users can regenerate them from My 2FA.

E-mail invitations

Invite and force 2FA for one user, a selection, everyone still missing, or the whole company in one click — with a personal message and a deadline.

Grace period & reminders

Let users postpone for a few days, then block. A daily job reminds anyone who has not enrolled.

Audit log

Who enabled, reset, bypassed or exempted what, when and from which IP. Retention is configurable.

Built with security in mind

  • Standard RFC 6238 TOTP (SHA-1, 6 digits, 30 s) — works with Microsoft Authenticator, Google Authenticator, Authy, 1Password, Bitwarden…
  • Uses Odoo's own brute-force protection (login cooldown) on every code check.
  • Setup secret lives server-side in the session, never in a form field.
  • Users cannot disable a mandatory 2FA from their preferences.
  • Only administrators can read or change overrides, bypass windows and policies.
  • «Remember this device» can be disabled (server-side, not just hidden).
  • Open-redirect-safe, CSRF-protected, no data sent to third parties.

FAQ

Can I turn it off without uninstalling?
Yes: Settings › 2FA Shield › 2FA enforcement › Disabled.

We already use Azure MFA. Do I need this?
You choose: require both, or tick «Trust single sign-on» so Azure users skip the Odoo code while password users are still covered.

Does it work for API / RPC?
It relies on Odoo's standard behaviour: accounts with 2FA enabled must use API keys for RPC.

Does it need a paid service?
No. Everything runs inside your Odoo, no external service, no tracking.

Which versions?
One package per branch for Odoo 17.0, 18.0 and 19.0.
