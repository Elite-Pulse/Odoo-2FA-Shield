2FA Shield - HR Departments

Department-based Two-Factor Authentication Policies

Extend 2FA Shield with Human Resources department integration. Define and enforce two-factor authentication policies based on employee departments, alongside the core 2FA Shield module.

  • Integrates with Odoo Human Resources.
  • Uses the core twofa_shield policy engine.
  • Automatically installs when its dependencies are installed.
  • Provides department-based policy configuration.

Requires the 2FA Shield module and Odoo HR.
