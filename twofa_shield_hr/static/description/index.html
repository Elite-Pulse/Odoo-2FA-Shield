2FA Shield - HR Departments

Department-based Two-Factor Authentication Policies

Extend 2FA Shield with Human Resources department integration. Define which employees must use two-factor authentication according to their HR department, while keeping policy enforcement managed by the core 2FA Shield module.

Odoo 17 Odoo 18 Odoo 19 HR Integration

Connect HR departments to 2FA enforcement

Organizations often need different authentication requirements for different teams. This integration connects Odoo HR department information with the core 2FA Shield policy engine, helping administrators manage authentication requirements according to employee department membership.

This is a companion module, not a standalone authentication solution. The core 2FA Shield module provides the underlying two-factor authentication functionality and policy enforcement.

Key features

Department-based policies

Use HR department membership as part of your two-factor authentication policy configuration.

HR integration

Connect authentication policy management with Odoo Human Resources departments.

Core policy engine

Rely on the core 2FA Shield module for authentication enforcement instead of duplicating its logic.

Integrated configuration

Manage department-related policy configuration through the companion module's integration with the core module.

Dependency integration

Declares the core 2FA Shield and HR modules as dependencies for a consistent installation.

Automatic installation

Configured for automatic installation when its declared dependencies are installed, according to the module manifest.

Requirements

  • A compatible Odoo 17.0, 18.0, or 19.0 installation, using the matching module branch.
  • The matching version of the core 2FA Shield module.
  • Odoo Human Resources (HR).

Install the matching version of each dependency. This module extends the core 2FA Shield functionality and does not replace the core module.
